# ATHENA

**A personal learning management and study organization system.**

## Overview

ATHENA is a personal project designed to centralize, organize, and manage learning resources, including courses, study materials, notes, and learning progress.

The project aims to reduce manual organization and establish a structured, maintainable environment for independent learning.

## Planned Features

- Course and study material organization.
- Automated file importing and classification.
- Structured storage of learning resources.
- Study progress tracking.
- Tools for managing and accessing educational content.

## Tech Stack

- **Python** — Automation and application logic.
- **Git & GitHub** — Version control.
- **GitHub Actions** — Continuous integration.
- **Dependabot** — Dependency maintenance.

Additional technologies will be documented as the architecture evolves.

## Development Workflow

Development follows a pull-request-based workflow.

1. Create an issue describing the task.
2. Create a dedicated development branch.
3. Implement and validate the changes.
4. Open a documented pull request.
5. Verify required CI checks.
6. Squash and merge into `main`.

Commit messages follow the Conventional Commits specification.
